## Text formatting

Regular paragraph text. **Bold**, *italic*, ~~strikethrough~~, and `inline code`.
You can combine them: ***bold italic***, **bold with `code`**.

Inline links: [Hugo documentation](https://gohugo.io/documentation/) and bare URLs auto-link too.

Abbreviations and superscripts: 10<sup>6</sup>, H<sub>2</sub>O.

Highlighted text with `<mark>`: <mark>highlighted</mark>.

Keyboard shortcut: <kbd>Cmd</kbd> + <kbd>K</kbd>.

## Headings

# H1 — reserved for the page title (do not use in content)
## H2 — main section
### H3 — sub-section
#### H4 — sub-sub-section

Anchor links are auto-generated by `render-heading.html` — hover a heading to see the `#` link.

## Code

Fenced code block with syntax highlighting (Chroma / Monokai theme):

```python
def fibonacci(n: int) -> list[int]:
    a, b = 0, 1
    result = []
    for _ in range(n):
        result.append(a)
        a, b = b, a + b
    return result

print(fibonacci(10))
```

```go
package main

import "fmt"

func main() {
    for i := 0; i < 5; i++ {
        fmt.Printf("iteration %d\n", i)
    }
}
```

## Steps

   Download the extended version from [gohugo.io](https://gohugo.io) or via Homebrew: `brew install hugo`.

2. Create a new site

   Run `hugo new site my-blog` to scaffold the project directory.

3. Add content

   Run `hugo server -D` and open `http://localhost:1313`.
